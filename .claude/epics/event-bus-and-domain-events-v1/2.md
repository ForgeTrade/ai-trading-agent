# Task: Core Types and Traits

## Description
Establish the foundational type system for the event bus by defining core traits, enums, and error types. This task creates the contract that all other components will implement and use for event communication.

## Acceptance Criteria
- [ ] Topic enum defined with all event types (MarketData, OrderCommand, ExecutionReport, PositionUpdate, RiskAlert, ControlCommand)
- [ ] EventPayload sum type created to hold all possible event payloads
- [ ] MessageBus trait defined with publish/subscribe methods
- [ ] Error types implemented (PublishError, SubscribeError, RecvError) with proper error context
- [ ] BusStream wrapper type created for async iteration over events
- [ ] All types implement required traits (Debug, Clone where appropriate)
- [ ] Documentation added for public interfaces

## Technical Details
- Use enum for Topic to ensure type safety and exhaustive matching
- EventPayload should be a sum type (enum) containing all event struct types
- MessageBus trait should be async and generic over error types
- Error types should use thiserror for proper error handling
- BusStream should wrap tokio mpsc receivers for ergonomic async iteration
- Consider using Arc<EventPayload> for performance on hot paths
