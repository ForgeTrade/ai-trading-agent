# Task: Graceful Shutdown

## Description
Implement graceful shutdown mechanisms for the event bus system. This includes proper handling of in-flight messages, controlled shutdown sequences, critical topic draining, and comprehensive metrics for shutdown operations. The implementation must coordinate with the existing InProcessBus structure.

## Acceptance Criteria
- [ ] accepting_publishes atomic flag implemented
- [ ] CancellationToken propagation throughout the system
- [ ] drain_topic() method for critical topics
- [ ] shutdown() method with configurable timeout
- [ ] Metrics for drained vs dropped events during shutdown
- [ ] Signal handling for graceful application termination
- [ ] Proper cleanup of all resources and background tasks
- [ ] Comprehensive tests for shutdown scenarios

## Technical Details
- Add AtomicBool accepting_publishes to prevent new messages during shutdown
- Implement tokio_util::sync::CancellationToken for coordinated shutdown
- Create drain_topic() to ensure critical messages are processed
- Add shutdown timeout with forced termination fallback
- Collect metrics on messages drained, dropped, and time to shutdown
- Handle SIGTERM/SIGINT signals for graceful application shutdown
- Ensure all async tasks are properly cancelled and joined
