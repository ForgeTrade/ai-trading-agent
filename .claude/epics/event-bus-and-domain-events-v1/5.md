# Task: Fan-out Router Implementation

## Description
Implement the TypedFanoutRouter struct with DashMap for efficient concurrent subscriber management. This router will handle message delivery to multiple subscribers with timeout handling, automatic slow subscriber detection and detachment, and enforcement of maximum subscriber limits per topic.

## Acceptance Criteria
- [ ] TypedFanoutRouter struct created with DashMap for subscriber storage
- [ ] route() method implemented with configurable timeout handling
- [ ] Subscriber management methods (add_subscriber, remove_subscriber) implemented
- [ ] Slow subscriber detection logic implemented (consecutive timeout tracking)
- [ ] Auto-detach mechanism for slow subscribers
- [ ] Maximum subscribers per topic enforcement
- [ ] Comprehensive unit tests for all router functionality
- [ ] Integration tests with actual message routing scenarios

## Technical Details
- Use DashMap<TypeId, Vec<Subscriber>> for thread-safe subscriber storage
- Implement timeout-based delivery with tokio::time::timeout
- Track consecutive timeout failures per subscriber
- Auto-detach subscribers after configurable consecutive failures
- Enforce max_subscribers_per_topic configuration
- Return routing statistics (delivered, failed, detached counts)
