# Task: Backpressure and Flow Control

## Description
Implement comprehensive backpressure and flow control mechanisms for the event bus. This includes per-topic timeout configuration, publisher blocking with timeout, slow subscriber tracking, circuit breaker patterns for sustained pressure, and reserve() support for critical message paths.

## Acceptance Criteria
- [ ] Per-topic timeout configuration implemented
- [ ] Publisher blocking mechanism with configurable timeout
- [ ] Slow subscriber tracking with consecutive timeout counters
- [ ] Circuit breaker implementation for sustained backpressure
- [ ] Reserve capacity mechanism for critical message paths
- [ ] Backpressure metrics collection and reporting
- [ ] Graceful degradation when capacity limits reached
- [ ] Comprehensive tests for all backpressure scenarios

## Technical Details
- Implement per-topic timeout configuration in TopicConfig
- Add publisher-side blocking when subscriber queues are full
- Track consecutive timeouts per subscriber for circuit breaking
- Implement reserve() method for critical path message prioritization
- Add backpressure metrics (queue depths, timeout rates, circuit breaker states)
- Use tokio::sync::Semaphore for capacity management
- Implement exponential backoff for retries
